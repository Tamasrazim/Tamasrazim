I use **Tamasrazim** online. I build software and creative tools across native Windows applications, games, browser-based workspaces, and procedural motion or vector experiments.

I’m interested in how an idea becomes a working system: its interface, underlying logic, inputs, saved state, output, and the limits that need testing. I learn by building, testing, and improving real projects.

**Not everything here is finished.** Some projects are usable now, some are experiments, and others are still in development. The project pages describe their current state and known constraints; I try not to present planned features as completed work.

## Areas I work on

- **Software and systems:** native Windows applications, project data, persistence, file workflows, and practical application behavior.
- **Games:** gameplay systems, input and controls, procedural generation, save data, and iterative prototyping.
- **Browser tools:** client-side utilities, supported local-file workflows, and interfaces that make their limitations clear.
- **Creative experiments:** procedural animation, vector artwork, icon systems, and audio-related interfaces.

Technologies appearing across these projects include **C++20, CMake, raylib, Rust/Tauri, JavaScript, HTML/CSS, and SQLite**. The stack varies by project; this is a list of tools used in my work, not a claim that every project uses all of them.
